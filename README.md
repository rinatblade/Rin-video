# Rin-video

Android-приложение: скачивание видео из TikTok, Instagram и YouTube без водяных знаков,
выбор качества перед загрузкой, кнопка «Поделиться», встроенный видеоредактор
(обрезка, удаление звука, наложение своей музыки, поворот), 20 тем и 30 русских шрифтов.

Сборка: GitHub Actions → APK в разделе Releases.
